# IGLOBALAGREECARE

Responsive corporate website built with Next.js App Router, TypeScript and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run build
```

Contact details, FAQs and trust badges are maintained in `lib/data.ts`. Email enquiries are handled by `app/api/quote/route.ts`; keep the Resend API key in local environment variables and never commit it.
